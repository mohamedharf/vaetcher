# Portfolio Screenshots Checklist & Guidelines

This directory is designated for high-resolution visual screenshots of the **Vaetcher** platform to showcase in your portfolio, case study presentations, or GitHub repository.

> **Important Confidentiality & Anonymization Rule:**
> When capturing these screens, ensure all real client business names, trademarks, and real individual contact details (e.g., real phone numbers or emails) are either absent or replaced with demonstration/dummy data.

---

## Recommended Screenshot Capture Specifications

- **Format:** PNG or WebP
- **Resolution:** 1920x1080 (Full HD desktop views) / 375x812 (Mobile view for Doctor Portal)
- **Browser State:** Clean browser window without developer tools or third-party extensions visible
- **Localization:** Capture key views in both Arabic (RTL) and English (LTR) where applicable to highlight bilingual capabilities.
